# Backend_CADê
Backend do "CADê", Projeto do 4° Semestre de ADS em 2026

1. **Certifique-se de que o Node.js está instalado**
   - Verifique se o Node.js está instalado no seu sistema executando:
     ```bash
     node -v
     ```

2. **Instale as dependências do projeto**
   - No terminal, navegue até o diretório do projeto (se ainda não estiver lá):
     ```bash
     cd Backend_CADe
     ```
   - Instale as dependências listadas no `package.json`:
     ```bash
     npm install
     ```

3. **Inicie o servidor**
   - Para iniciar o servidor, execute:
     ```bash
     npm start
     ```
   - O servidor será iniciado e estará disponível na porta padrão (geralmente `3000`).

4. **Acesse o servidor**
   - Abra o navegador e acesse:
     ```
     http://localhost:3000
     ```
